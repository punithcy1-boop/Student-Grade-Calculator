# Student-Grade-Calculator
A Java-based project that calculates a student's total marks, percentage, and grade using user input, loops, and conditional statements.
## Features

- Takes student name as input
- Accepts marks for 5 subjects
- Calculates total marks
- Calculates percentage
- Displays grade

## Example Output

Student Name: Punith
Total Marks: 440
Percentage: 88.0%
Grade: A

## Technologies Used

- Java
- Scanner
- Loops
- If-else conditional statements
